# Frozen learned-feature ablation

This exploratory analysis is specified after the original confirmation outcomes were observed. It is a sensitivity check of an existing frozen head, not a new held-out evaluation or a retrained component ablation. No variant is chosen for deployment from its results.

Run `scripts/analyze_frozen_components.py` to create a new result directory; `--verify` checks the delivered saved analysis. The English 300-claim confirmation and each of the six multilingual 100-query variants are reported separately. There is no pooled independence assumption or significance test.

The original combined head has 13 inputs: nine English NLI probability statistics followed by four embedding cosine statistics. Four variants are fixed before this analysis executes: full; NLI inputs replaced with their original training means; embedding inputs replaced with their training means; both groups replaced with training means. Mean replacement sets each removed group's standardized contribution to zero while preserving the original coefficients, intercept, scales and threshold of 0.5. It does not refit the retained features or simulate retraining without them. Removing both groups leaves the intercept-only decision.

Each variant selects or abstains on the same original no-gate candidate, retaining its numerical and structural checks. It cannot create a new answer, explanation or model response. Full-head probabilities and candidates must reproduce the original combined policy. The preliminary replay checks the original benchmark labels; the masking function receives no labels. Masked decisions are saved before this script scores them. Accuracy counts abstention as an error; accepted accuracy is null when no answer is retained. The report also counts correct and incorrect answers added or removed relative to the full head. Existing benchmark labels remain unchanged. Cross-platform replay allows the established absolute numerical tolerance of 1e-12 for floating-point calculations while preserving discrete decisions and original file receipts.

The metadata inventory separately records the presence of explicit source URLs, source-type fields, publication-date fields and provenance-family IDs in the saved retrieved contexts. The current English and multilingual learned feature schemas contain no source-type, publication-date or provenance-family inputs. Document IDs and identical-text collapse are not verified independent-source families. Dates are not invented from years mentioned in claim text.

Source-type and date-head ablations are therefore unavailable for this controller. Previous AVeriTeC provenance models and independent source-origin/snapshot guards are separate components; this analysis does not erase their existence, measure their causal benefit, or integrate them into the neural gate. Missing inputs cannot be declared successfully ablated. The remaining trained provenance, temporal, family and robustness experiments are not completed by this analysis.

All original sources, models, caches, fits, results and research scope are preserved. No neural inference, training, threshold tuning, manuscript or GitHub action is performed.
