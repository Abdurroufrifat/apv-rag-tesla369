# Grouped multilingual correctness calibration

This stage uses the verified 660-query/2640-policy retrieved-controller export. No neural model is run, no benchmark label is newly annotated, and no generator answer, gate decision or threshold is changed.

## Fixed method

Five folds are assigned before calibration by sorting unique integer claim IDs on SHA256 of `apv-multilingual-calibration:369:<claim_id>` and assigning sorted positions modulo five. Each of the sixty claim IDs belongs to one twelve-ID fold. All eleven parallel variants stay together. Outcomes and labels do not determine fold membership.

For each held-out fold and each of the four policies, the existing English FEVER calibration implementation fits a logistic model with C=1 to the logit of the raw English-NLI score assigned to the final accepted generated label. Its binary target is correctness against the upstream benchmark label. Training uses accepted rows belonging only to the other forty-eight IDs, pooling languages equally by row. There is no language-specific fit, feature/penalty search or confidence-threshold selection. A separate constant-confidence control uses Beta(1,1)-smoothed development correctness prevalence from the identical training folds. Compare logistic losses against this control as well as raw NLI scores. Single-outcome training uses the existing Beta(1,1) prevalence fallback; no accepted training answers makes confidence unavailable.

The runner writes the fold allocation, twenty calibrators and their development/held-out IDs before writing out-of-fold confidence predictions. Prediction contains no correctness target. Every evaluation confidence is generated by the model that excluded its claim and all parallel variants. Original abstentions retain null confidence. Fits and compact prediction receipts bind the verified source, separate gold file, code and this protocol. Source experiment files remain unchanged.

## Evaluation and limits

For every file/policy, compare raw and cross-fitted binary Brier, NLL and fifteen equal-width-bin correctness ECE on the same available accepted answers. Preserve all outcomes, including any logistic-model losses worse than the prevalence control. Report accuracy at top 50%, 80% and 100% of evaluable accepted answers under each ranking, without tuning thresholds. A pooled summary is descriptive row-weighted reporting, not inference on 660 independent claims. Abstentions count as errors in all-query accuracy; confidence fitting does not alter accuracy, acceptance or explanations.

These claims and model results were already inspected during earlier experiments. This post-result design therefore provides exploratory grouped cross-validation, not a new independent confirmation cohort. Claim grouping prevents translation-ID overlap within fitting/evaluation; different claims can still share excerpts. No significance or uncertainty claim is made. The limited, target-derived excerpt pool and English-trained gate/embedding limitations persist. Cross-fitted models are evaluation models; no deployment model is refitted on all sixty claims. Independent new-claim validation remains needed before making calibrated deployment claims.
