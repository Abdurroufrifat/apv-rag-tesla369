# Phase 1A Research-Gap Audit

**Audit date:** 2026-09-05  
**Status:** working gap statement; update before submission  
**Purpose:** prevent the paper from claiming components as novel when recent work already covers them.

## Decision

The broad proposal “provenance-aware RAG with reliability, redundancy filtering, sufficiency, and abstention” is **not sufficiently novel by itself** in 2026. Recent work already studies each of those ideas separately. The project therefore adopts a narrower and testable contribution:

> **Can a RAG verifier distinguish independent corroboration from many derivative copies of the same unsupported attribution?**

The working system name remains **APV-RAG**, but the key technical object is now a **temporal provenance-family graph**. Web documents that repeat or derive from one upstream source are treated as one evidence family rather than independent votes.

## Closest work and resulting design changes

| Prior work | What it already contributes | What APV-RAG must add beyond it |
|---|---|---|
| Hwang et al., “Retrieval-Augmented Generation with Estimation of Source Reliability,” EMNLP 2025 | Estimates heterogeneous source reliability and uses weighted aggregation | Model dependence among sources; test copied pages that appear to be separate sources |
| Li et al., “IMRRF,” NAACL 2025 | Multi-source retrieval plus redundant-information filtering for fake-news detection | Distinguish harmless semantic redundancy from genealogical dependence; retain lineage rather than only filtering text |
| Alt et al., “User-Centric Evidence Ranking for Attribution and Fact Verification,” EACL 2026 | Ranks complementary evidence while balancing sufficiency and redundancy | Evaluate whether apparently complementary pages actually descend from one origin |
| Qiu et al., “SURE-RAG,” arXiv 2026 | Evidence-sufficiency verification, uncertainty, and selective answering | Treat archive absence, inaccessible evidence, and provenance dependence as explicit causes of insufficiency |
| Zhu et al., “TROVE,” ACL 2025 | Sentence-level provenance tracing and relationship classification | Construct document-level historical transmission families across dates, mirrors, quotations, and citations |
| Deng et al., “PAGE-RAG,” arXiv 2026 | Provenance-aware graph evidence promotion for multi-hop QA | Target source independence and false corroboration rather than path selection for multi-hop answering |
| Jeong et al., “Stable-RAG,” ACL 2026 | Measures and mitigates sensitivity to retrieval-document permutations | Measure sensitivity to copy count while keeping underlying information constant |
| Glockner et al., EMNLP 2022 | Shows that missing counter-evidence makes many fact-checking settings unrealistic | Preserve reproducible negative-search logs and avoid converting “not found” into “false” |
| Schlichtkrull et al., AVeriTeC | Real-world web claims with evidence and four-way verdicts | Add historical attribution, archive/OCR metadata, and derivative-source families |
| Akhtar et al., “Ev2R,” TACL 2026 | Evaluates retrieved evidence using reference and verdict support | Add an independence-sensitive evaluation slice and copy-amplification measure |

## Retained contribution claims

These are **working claims**, not “first-ever” claims. A final systematic search is required before the manuscript uses priority language.

1. **Provenance-family evidence aggregation.** Evidence weight is assigned to independently traceable source families, not raw document count.
2. **Controlled copy-amplification evaluation.** The same informational origin is reproduced as 0, 1, 5, 10, or 25 derivative pages while semantic content and genuine evidence remain fixed.
3. **Repetition-Induced Belief Shift (RIBS).** RIBS measures the change in support probability caused only by adding derivative copies:

   \[
   \operatorname{RIBS}_k(c)=p_\theta(y=\text{support}\mid E\cup C_k)-p_\theta(y=\text{support}\mid E),
   \]

   where \(C_k\) contains \(k\) derivative copies from the same provenance family. A robust verifier should keep \(|\operatorname{RIBS}_k|\) small when no independent evidence is added.
4. **Historical scientific-attribution benchmark.** SciAttr-369 records primary-source pointers, earliest located occurrences, negative-search logs, OCR status, and provenance-family relations.
5. **Archive-aware abstention.** The model distinguishes contradiction from evidence that is missing, inaccessible, OCR-corrupted, or only available through later repetition.

## Revised working title

**Counting Copies Is Not Corroboration: Provenance-Family-Aware RAG for Historical Scientific Attribution Verification**

Suggested subtitle for presentations and the case-study section:

**The Tesla 3-6-9 Narrative as a Controlled Case Study**

## What this project does not claim

- It does not claim that 3, 6, and 9 have mystical or scientifically privileged properties.
- It does not treat web repetition as historical authentication.
- It does not treat an unsuccessful search as proof that a statement was never made.
- It does not claim that source reliability, redundancy filtering, provenance, or abstention alone are new.
- It does not use LLM-generated judgments as dataset ground truth.

## Go/no-go standard after the pilot

Continue only if the first 20 claims show at least five meaningful provenance families, at least two cases of copy-amplified unsupported attribution, and annotators can reliably distinguish `misattributed`, `contradicted`, and `insufficient`. If these conditions fail, broaden the pilot to additional scientists before implementing the full model.
