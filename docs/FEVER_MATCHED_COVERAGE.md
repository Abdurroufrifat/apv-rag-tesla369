# Frozen FEVER answer-selection analysis

This analysis is specified after the integrated FEVER confirmation results were observed. It adds no inference, model fitting, threshold search or policy change. The input export is checked by the existing full pipeline auditor before analysis. All original predictions, protocol files and calibration fits remain unchanged.

For each of the three learned gates at its frozen 0.5 threshold, count final accepted answers after numeric checks. Select exactly the same number from the no-gate accepted population using two controls: descending NLI score assigned to the generated label, and descending mean passage/claim embedding cosine. Ties preserve the frozen claim order. Neither selector receives gold labels. A gate answer must be identical to the corresponding no-gate answer; otherwise the comparison fails. Abstentions remain distinct from Not Enough Evidence predictions. The analysis records selected IDs for inspection.

Report accepted-answer accuracy and paired all-claim accuracy differences. Form transitive groups using normalized claim text or any visible retrieved page ID. Use 2,000 group bootstrap resamples and two-sided group sign swaps on correctness differences, seed 369. Enumerate swaps exactly when at most twelve group contributions are nonzero; otherwise use 10,000 Monte Carlo swaps with the plus-one p-value. Apply Holm correction to the six comparisons in this analysis only. Resampling is conditional on frozen rankings and gate selections; it does not refit anything.

Matched counts are observed gate operating points, not fitted deployment thresholds for the controls. Public FEVER data, prior adaptive searches, paraphrase dependence and potentially overlapping pretraining limit inference. Page grouping can be conservative or miss dependence. These descriptive tests do not turn a post-result analysis into preregistered confirmation. No winner is selected, no old output is replaced, and no neural models or Wikipedia archive need to be downloaded again.
